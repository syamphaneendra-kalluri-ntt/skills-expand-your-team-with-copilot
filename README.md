## 🎯 About This Repository

This is a GitHub Skills exercise repository featuring a sample application: **Mergington High School Activities** - a web app for students to view and sign up for extracurricular activities.

**Technology Stack:**
- Backend: Python with FastAPI
- Frontend: HTML, CSS, JavaScript
- Database: MongoDB

Practice issues (#3-#9) are available for you to assign to Copilot and see it in action!
