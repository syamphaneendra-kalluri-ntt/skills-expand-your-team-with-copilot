## Understanding the Exercise

The GitHub Skills exercise teaches you how to:
1. ✅ Enable Copilot coding agent on your repository
2. ✅ Assign issues to Copilot
3. Watch Copilot create a PR and work on the issue
4. Review Copilot's work and provide feedback
5. Iterate with Copilot until the work is complete
6. Merge the PR when satisfied

You're currently at Step 2. The instructions in Issue #1 show you what to do next!
