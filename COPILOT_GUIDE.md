# Working with GitHub Copilot Coding Agent

This repository is part of the **GitHub Skills: Expand your team with Copilot** exercise.

## For Exercise Participants

If you're completing this exercise, note that:

- **Issue #1** is the main exercise tracker with instructions - it should NOT be assigned to Copilot
- **Issues #3-#9** are sample feature requests that CAN be assigned to Copilot for practice
- When you assign an issue to Copilot, it will:
  1. Create a new branch (usually named `copilot/*`)
  2. Create a pull request linked to the issue
  3. Work on implementing the requested changes
  4. Request your review when complete

## Tips for Working with Copilot Coding Agent

### Creating Good Issues for Copilot

1. **Be Clear**: State the problem and desired outcome explicitly
2. **Provide Context**: Include relevant details about the codebase or requirements
3. **Set Acceptance Criteria**: Define what "done" looks like
4. **Break Down Large Tasks**: Smaller, focused issues work better than large ones

### Example Good Issue

```markdown
Title: Add Manga Maniacs Activity

The manga club was recently announced and is missing from the website. Please add it.

Details:
- Description: Explore the fantastic stories of the most interesting characters from Japanese Manga (graphic novels)
- Schedule: Tuesdays at 7pm
- Max attendance: 15 people
```

### Collaborating with Copilot

- Use `@copilot` in PR comments or reviews to trigger Copilot to act on feedback
- Regular comments (without `@copilot`) won't start a new coding session
- You can provide feedback mid-session using the session chat interface
- Review Copilot's work just like you would a human teammate's PR
